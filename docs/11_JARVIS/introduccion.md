# J.A.R.V.I.S

**Jarvis** es un acrónimo de *Just A Rather Very Intelligent System*.

Hay muchas funciones que un sistema de IA decente puede desempeñar. Empecemos por crear un
agente pequeño capaz de:

- **Responder preguntas** que un experto en seguridad podría contestar.
- Hacer **análisis de seguridad de código Python**; contamos con algunas bases de datos para
  empezar.
- **Dar pautas** para abordar vulnerabilidades de seguridad. Esto será delicado para aquellas
  vulnerabilidades que no se resuelven simplemente actualizando una librería.
- **Revisar las métricas del sistema** en busca de anomalías en las últimas 24 horas, usando
  algoritmos de [detección de anomalías](../02_UNSUPERVISED_LEARNING/deteccion_de_anomalias.md).
- **Generar informes** de seguridad.
