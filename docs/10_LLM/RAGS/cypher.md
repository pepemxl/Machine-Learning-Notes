# Cypher

**Cypher** es un lenguaje declarativo de consulta de grafos que permite consultar datos de forma
expresiva y eficiente sobre un *property graph*.

Cypher fue en gran medida una invención de Andrés Taylor mientras trabajaba en Neo4j, Inc.
(antes Neo Technology) en 2011. Originalmente estaba pensado para usarse con la base de datos de
grafos Neo4j, pero se abrió mediante el proyecto **openCypher** en octubre de 2015.

El lenguaje se diseñó teniendo en mente la potencia y las capacidades de SQL —el lenguaje de
consulta estándar del modelo relacional—, pero partiendo de los componentes y necesidades de una
base de datos construida sobre los conceptos de la teoría de grafos.

En un modelo de grafo los datos se estructuran como **nodos** y **relaciones**, para centrarse en
cómo las entidades de los datos están conectadas y relacionadas entre sí.
