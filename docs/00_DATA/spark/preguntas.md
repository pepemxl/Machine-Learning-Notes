# Preguntas de Práctica: PySpark

Preguntas de repaso y entrevista sobre PySpark. Ver [PySpark](pyspark.md) y
[Ejemplos](ejemplos_pyspark.md) para el material de apoyo.

1. ¿Qué es una `SparkSession` y cómo se crea una en PySpark?
2. Escribe un fragmento de PySpark que haga un `groupBy` y calcule el promedio de una columna.
3. Explica el concepto de **evaluación perezosa** (*lazy evaluation*) en PySpark.
4. Escribe código PySpark que una dos DataFrames y explica los distintos tipos de `join` disponibles.
5. ¿Cómo guardas un DataFrame en un archivo Parquet? Da un ejemplo.
6. ¿Qué son las UDF en PySpark? Escribe una UDF sencilla y muestra cómo se usa.
7. Explica el concepto de **variables de difusión** (*broadcast variables*).
8. Escribe código PySpark que haga una operación `pivot` sobre un DataFrame.
9. ¿Cómo optimizarías un job de PySpark? Enumera algunas técnicas.
10. Escribe código PySpark que lea datos de un archivo JSON y muestre el esquema.
11. ¿Para qué sirve el método `withColumn`? Da un ejemplo.
12. Explica la diferencia entre las transformaciones `map` y `flatMap`.
13. Escribe código PySpark que calcule la correlación entre dos columnas de un DataFrame.
14. ¿Cómo se usan las **funciones de ventana** (*window functions*) en PySpark? Da un ejemplo.
15. ¿Cuál es el papel del **optimizador Catalyst** en PySpark?
16. Escribe código PySpark que elimine filas duplicadas de un DataFrame.
17. Explica cómo se usa la función `agg` con un ejemplo.
18. Escribe código PySpark que lea datos de una tabla Hive y muestre los resultados.
